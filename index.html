Sieve: AI resume screening

Ranks applicants against a job with a score HR can verify line by line.

▶ Live demo GitHub

Recruiters get hundreds of resumes per role, and keyword filters are easy to game. In Sieve, the AI reads the resume, but plain code decides the score. Every point links to a quote from the resume, so a recruiter can see exactly why someone ranked first.

Resumes arrive by upload or straight from a careers inbox through the Gmail API, which routes each one to the right job. HR shortlists or rejects, and the email is previewed before it goes out.

WORLD 2 · LIVE

Away: AI leave-tracker agent

Employees book leave by chatting with an AI agent that can't break the rules.

▶ Live demo GitHub

A leave tracker for two companies. Employees apply from a calendar or by chatting with an AI agent with 13 tools. The agent walks them through type, dates, balance, clash check, reason and confirmation. Project managers approve requests, and a business analyst automatically covers while the PM is away.

The key design choice: the AI can only propose, never book. Balances, clash rules, permissions and company isolation are enforced in Python, and nothing is written until the user says yes.

HR Policy Assistant (RAG)

Answers employee policy questions only from the handbook, with citations.

GitHub

A plain chatbot makes up HR policy. This assistant answers questions about leave, benefits, expenses and conduct only from 15 real handbook pages, cites every claim, and refuses when the policy doesn't cover the question.

retrieve.pysimplified from the repo
def reciprocal_rank_fusion(*rankings, k=60):
    """Each list votes 1/(k + rank); shared hits rise."""
    score = {}
    for ranking in rankings:
        for rank, cid in enumerate(ranking):
            score[cid] = score.get(cid, 0.0) + 1.0 / (k + rank + 1)
    return sorted(score, key=score.get, reverse=True)
